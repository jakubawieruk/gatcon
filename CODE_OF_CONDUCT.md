# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

Please read the full text here:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project, you are expected to uphold this code.

**jakubawieruk@gmail.com**. All reports will be reviewed and handled confidentially.
